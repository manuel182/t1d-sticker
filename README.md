# T1D Medical Device Sticker Generator

A free web tool to create emergency stickers for the phones of people with Type 1 Diabetes.

## What it does

Enter a name and an emergency contact number → download a printable PNG sticker with:

- T1D medical awareness symbol
- "THIS IS A MEDICAL DEVICE"
- "IF FOUND PLEASE CALL:"
- Name and phone number

## Features

- 🔒 100% private — runs entirely in your browser, nothing is uploaded
- 📱 Works on iPhone, Android, desktop
- 🌐 German / English
- 🎨 High-resolution PNG (1200×1500 px, transparent background)

## Disclaimer

This generates a graphic template only. **It does not replace an official medical emergency ID.** Use at your own risk.
